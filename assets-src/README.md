# assets-src

Source art: Blender, Adobe and AI-generated files. Never shipped directly; exported assets go through the pipeline into `client/`.

Heavy binary formats are stored with Git LFS (see `.gitattributes`). Run `git lfs install` once before committing here. Naming, folders and workflow: `docs/asset-workflow.md`; check with `node tools/asset-naming/asset-naming.mjs`.
