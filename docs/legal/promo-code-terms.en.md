# HypeDomino Promo Code Terms

> **Draft for legal review. Not legal advice. Not published.** English master of the promo code terms (#195). Source: `docs/economy.md` section 8 and EP-5. Placeholders `[[LP-n]]` and counsel questions are listed in [README.md](README.md).

Version: [[LP-12: version and effective date]]

These terms are part of the [terms of use](terms-of-use.en.md) and apply to every promo code for HypeDomino, issued by [[LP-1]].

## 1. What a promo code is

A promo code is a code you enter in the game to receive the rewards of a campaign. Promo codes are free: they are never sold, by us or by anyone with our permission. Rewards of a code bought from someone else may be taken back (section 5).

## 2. What a code can give

- Coins, cosmetic items and pass XP, as the campaign states.
- Some codes unlock the premium Hype Pass track of the pass season running when you redeem the code. Premium rewards of the levels you have already reached unlock at once.
- A code never gives crystals directly, a medal, a chest or a real-money product.
- Rewards from a code follow the terms of use, section 5: they have no cash value and cannot be traded, transferred or exchanged for money.

## 3. Kinds of codes

| Kind | Who can use it | How often |
|---|---|---|
| Single-use | Anyone who has the code | Once in total |
| Multi-use | Any account | Once per account, until the campaign's limit is reached |
| Targeted | Only the accounts the campaign names | Once per named account |

## 4. Validity

- Each code works only between the start and end of its campaign, in server time (UTC).
- A code stops working when its limit of redemptions is reached or when we turn it off.
- Codes are not case-sensitive.
- A code that unlocks the premium Hype Pass track works only while a pass season runs and only if you do not already have the premium track of that season. If either is not the case, the code is not used up and you can try again later.

## 5. Limits and misuse

- To protect codes against guessing, the number of attempts is limited. Too many wrong codes pause code entry for a while.
- We may turn off a code that was leaked, guessed or redeemed in an unusual pattern.
- We may take back rewards obtained by guessing codes, automated entry, several accounts, or a code obtained for money, and treat this as a breach of the fair play rules of the terms of use.

## 6. Campaigns with partners

A code may be handed out by us or by a partner as a reward of a campaign, for example a crowdfunding reward. The campaign's own conditions say who receives a code. The rewards and the redemption follow these terms.

## 7. No payment, no refund

Since nothing is paid for a code, there is nothing to refund. [[COUNSEL: CQ-7, whether this exclusion holds for consumers, in particular for codes that are a reward of a paid crowdfunding pledge]]

## 8. Contact

Problems with a code: Settings, Support in the game, or [[LP-2: support email]].
